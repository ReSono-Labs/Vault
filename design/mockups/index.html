01 · Today

Your day, composed into cards.

The Today sheet is raised. A large light-weight count is the only headline. Under it are three quick chips and a two-column grid of frosted cards. The cards hold solid white inner cards that look like they lift off the glass.

  • Glance chips: time to the next event, the latest order, and the weather.
  • Corner actions: bookmark saves to Memory, folder saves to Files.
  • Red dot: something changed since you last looked.

Where it comes from

Every card is a Vault capability.

  • 5 tasks: the local task list, filtered to today.
  • 12 min: the next calendar event (CalDAV/ICS) and travel time to it.
  • Sister: a composed card. Contacts + Memory (“Maya’s birthday Sat”) + Tasks.
  • Travel: a trip you mentioned (Memory), watched with web search.
  • Finance / Events / Discover: the markets, local events and news plugins, ranked by your preferences in Memory.
02 · Arrival

Calm by default. Things arrive.

With the sheet resting, the aurora fills the top half and the screen feels like it’s breathing. Live events drop in as a white toast just under the Dynamic Island, then fold into the right card.

  • Invite: add someone to your household Vault (local accounts).
  • Headset: Voice. A red dot means a session is waiting.
  • Avatar + badge: you, with unread mail. Tap it for Settings.
  • B: the Background Agent. A red dot means it needs you.

How it works

Events, not polling.

  • Toast: the mail integration recognizes an order confirmation in IMAP and sends a notification UI part.
  • Sheet: drag it up for the full Today grid, or down for calm. On desktop it’s just the grid.
  • Order: cards are ranked by urgency × relevance (Memory). Pin or dismiss and Vault learns. That’s procedural learning, read-only.
03 · Ask → Generative UI

Answers arrive as interfaces.

“Plan Maya’s birthday on Saturday.” Vault replies in a short sentence, then streams in cards one at a time. Each one pops up from the input bar: a timeline, restaurant options you can pick from, and a pink approval card for the only step that does something in the real world.

  • Source chips (Calendar, Web, Memory) show where each card came from.
  • Shimmer: the next part is still streaming.
  • Chips above the input: Live Memory and tool routing reacting while you type the next message.

How it works

Three kinds of generated UI.

  • Tool cards: Calendar, Web, Markets… return typed results, and each type has a registered component. No extra tokens, nothing malformed.
  • Composed views: the agent calls present() with a JSON spec built only from Vault’s catalog. The server validates it before it streams.
  • Approvals: any write action renders as this card. Tapping goes through the normal grant and confirmation path. The UI itself never touches data.
04 · Voice

The orb listens. Memory floats in.

Hold the orb in the input bar and the sheet sinks away. The aurora speeds up and the orb grows to fill the screen. Your words appear as you speak. Before you finish, the memories and the likely tool show up as glass chips around the orb.

  • Same engine as Chat: live transcription, Live Memory over pgvector, and provisional routing from the Decisions API.
  • Provisional: nothing runs until you stop talking. Routes are hints, not actions.

How it works

Voice agents present too.

  • Realtime models (OpenAI, Gemini Live, xAI) can’t stream UI markup mid-sentence, but they can call tools. present() is a tool, so voice answers turn into cards in the same way.
  • When you finish speaking, the gift cards pop into the sheet while Vault is still talking.
  • Longer jobs are handed to the Background Agent and show up as a B card with progress.
