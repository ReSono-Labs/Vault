# starter.example

This starter combines one Skill, one saved setting and one MCP tool. Replace the
name and description, then implement the MCP endpoint in `server.py` with your
preferred MCP Python library. Run it on `127.0.0.1:8788` before enabling the
plugin in Vault.

Vault treats the server as a separate service. It does not execute `server.py`
inside Vault.
