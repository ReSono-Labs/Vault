Explicit owner replies during full-build continuation:

BP-R01: Live Memory persists per user/workspace and is initially On. Off still
disables preparation only; normal final retrieval and post-session factual review
continue. No global switch that changes another user's setting. Partial drafts
may reach the configured provider for testing as already approved, never become
durable learning evidence. Availability/errors fall back truthfully, not fake recall.

BP-R02: Automatically activate learned read-only rules. This does not grant tools,
bypass confirmations, permit pre-final tool calls or authorize automatically
activating write rules. Validate final evidence, rule/schema/capability identity,
current generation/availability, current grants and final meaning before use.
Unknown/mixed effects are not read-only; fallback rather than infer permission.
Confidence/retrieval/quality checks remain necessary implementation gates; no
numeric activation threshold or write activation policy was supplied.

BP-R03: Retain session history after forgetting, but suppress relearning of the
forgotten fact from later reviews/rebuilds. Canonical forgetting still erases the
memory/vector; source-history retention is not permission to resurrect it.
Suppression must survive reviewer/rebuild/version changes and remain scoped;
account erasure removes associated private suppression data. Explicit later user
reintroduction requires separately attributable evidence, not silent history replay.

BP-R04: Complete the full grounded build, tracking real progress. Use correct
targeted tests and move on; reserve broad suites for major integration checkpoints,
not repeated small deltas. Required authorization/migration/causal/revision safety
proof is not waived. No feature is complete merely because an unmounted port exists.

Material gate: these literal replies resolve default/scope, read-only activation
direction and history retention/suppression. Existing proposed defaultOff/fully
inactive policy is superseded only in these concerns. Grounding still controls
modularity, canonical ownership, exactly two identities and no speculative effects.
